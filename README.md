# Westcoast Education – Desktop (Assignment 2)
 
A cross-platform desktop application built with **Avalonia** and **.NET 10** for Westcoast Education's
course leaders and administrators. It manages courses, students and teachers, with all data stored in
**RestDb.io**.
 ## Features
 
| Area | Functions |

|---|---|

| Courses | List, add, **update**, delete |

| Students | List, add |

| Teachers | List, add, manage area of expertise, **update** information |
